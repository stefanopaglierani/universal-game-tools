# Changelog

All notable changes to this repository are documented here.
Each implemented module also keeps its own `CHANGELOG.md`.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and modules use [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added
- Initial repository structure for UPTG, UPRG and UPWG.
- Root README, changelog and license.
- Documentation structure (`Documentation/architecture`, `Documentation/development`).
- Project instructions and development workflow docs.
- UPTG architecture specification, draft 0.1 (under review, not implemented).
- Italian versions (`.it.md`) of the documents.
- UPTG 0.1.0, released as tag `uptg-v0.1.0` (see the module `CHANGELOG.md`).
- ADR-0007 and ADR-0008, recording decisions taken during UPTG Milestones A and D.
- ADR-0009: UPTG is a private tool and only its baked output goes into a game.
- UWR, the Universal World Reader (ADR-0014).
- UPWG, the standalone world editor, first version (ADR-0015), and UPTG land shapes beyond the island.
- UPRG 0.1.0, released as tag `uprg-v0.1.0` (see the module `CHANGELOG.md`), with architecture 0.2 and ADR-0010 to ADR-0013.

### Changed
- The repository is English only: the Italian `.it.md` documents were removed (Stefano, 2026-11-11).
- Root README, documentation index and architecture overview updated for UPTG 0.1.0 and the UPTG addon layout (R12).
